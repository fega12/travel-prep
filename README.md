# 家庭出游用品准备清单

一个**纯前端、零依赖、单文件**的家庭出游打包 Checklist 网页应用。内置「一家四口（2 大 2 小）」出行常用物品清单与「出门前家中检查」清单，勾选即代表已装入行李，实时统计准备进度，告别出门前手忙脚乱、漏带东西。

> 项目入口文件：`travel-prep.html`（整个应用就这一个文件，无需联网、无需安装依赖）。

---

## 1. 项目解决什么问题

家庭出游（尤其带婴幼儿/儿童）打包时经常遇到：

- 东西多、易漏项：证件、药品、儿童专属用品分散，临出门才发现没带。
- 分工不清：不知道某样东西该谁准备、带几件。
- 进度没概念：到底装好多少、还剩多少，全凭脑子记。
- 离家前家中安全：燃气、门窗、宠物没人逐条确认，出门了还不放心。

本项目用一个清晰的清单 + 进度条 + 责任人/数量标注 + 出门前家中检查，把「打包」和「离家前确认」两件事结构化，降低遗漏率。

## 2. 主要功能

| 功能 | 说明 |
| --- | --- |
| 🧭 **行程信息** | 填写目的地、出发/返程日期，自动计算出行天数并展示在顶部。 |
| 👨‍👩‍👧‍👦 **家庭成员** | 默认 4 名成员（爸爸/妈妈/大宝/小宝），可改名、可换 emoji。 |
| 📊 **进度统计** | 顶部实时显示「已准备 X / 总数」「待准备」数量与进度条。 |
| 🗂️ **分类清单** | 8 大类：证件&财务、衣物、洗漱&护肤、电子&充电、药品&健康、儿童专属、途中&食物、其他&应急。 |
| 🙋 **责任人 & 数量** | 每项标注「适用成员」头像与建议数量（如尿不湿 ×20），便于分工与采购。 |
| 🔍 **搜索 & 筛选** | 关键字搜索（如「充电器」「退烧药」）；按「全部 / 待准备 / 已装好」筛选。 |
| ➕ **增删自定义** | 每类可添加物品（含负责人）或删除某项，适配不同行程。 |
| 📂 **折叠分组** | 类别可折叠/展开，清单长也不乱。 |
| 🏠 **出门前家中检查** | 独立区块：关燃气、锁门窗、关电器、托付宠物等 14 项，出发当天逐条确认再锁门。 |
| 🖨️ **打印清单** | 一键打印（自带打印样式：隐藏按钮/搜索框，仅留清单，方便随身带或贴墙上）。 |
| ↺ **重置** | 一键恢复默认清单（清空勾选与自定义项）。 |
| 💾 **本地保存** | 所有数据存于浏览器 `localStorage`，刷新/关闭不丢失。 |

> ⚠️ **数据说明**：数据仅保存在当前浏览器本机，换电脑/换浏览器**不会同步**。清理浏览器缓存会丢失数据。

## 3. 安装方法

无需安装、无需构建、无第三方依赖。两种方式任选其一：

### 方式 A：直接打开（最简单）
双击 `travel-prep.html`，或在浏览器中打开它即可使用（推荐 Chrome / Edge / Safari / Firefox 等现代浏览器）。

### 方式 B：本地起一个静态服务（可选）
若想用 `http://localhost` 方式打开，可在项目目录下执行：

```bash
# Python（系统自带）
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000/travel-prep.html
```

或用 Node：

```bash
npx serve .
```

## 4. 使用方法

1. **填行程**：在顶部填写「目的地、出发日期、返程日期」，天数自动算出。
2. **改成员**：点成员头像可换 emoji，点名字可改名（如改成真实称呼）。
3. **打勾打包**：逐项勾选已装入行李箱的物品，进度条与统计实时更新。
4. **搜索/筛选**：用搜索框快速定位物品；用「待准备 / 已装好」快速看遗漏项。
5. **自定义**：在某类别底部输入框添加物品并选择负责人；点 `✕` 删除。
6. **离家前确认**：展开「🏠 出门前 · 家中检查」，逐条勾完再锁门。
7. **打印**：点「🖨 打印清单」导出纸质版随身带。
8. **重置**：点「↺ 重置」恢复默认清单（会弹出确认）。

## 5. 输入 / 输出示例

### 输入（用户操作）
- 行程：目的地「三亚」、出发 `2026-08-20`、返程 `2026-08-25` → 自动算出 **共 6 天**。
- 成员：保留默认 爸爸 / 妈妈 / 大宝 / 小宝。
- 勾选：勾上「身份证、泳衣/泳裤、防晒霜、尿不湿」等已备好的项。
- 搜索：「退烧药」→ 仅显示药品类的「退烧药(儿童专用)」。
- 新增：在「电子&充电」类添加「自拍杆」，负责人选「妈妈」。
- 家中检查：勾上「关闭燃气总阀 / 灶具」「锁好门窗」等。

### 内部数据模型（localStorage 键：`family_travel_prep_v1`）
应用状态为一个 JSON 对象，结构示意：

```json
{
  "members": [
    { "name": "爸爸", "emoji": "👨" },
    { "name": "妈妈", "emoji": "👩" },
    { "name": "大宝", "emoji": "🧒" },
    { "name": "小宝", "emoji": "👶" }
  ],
  "cats": [
    {
      "id": "doc", "icon": "📄", "name": "证件 & 财务",
      "items": [
        { "n": "身份证", "w": [0, 1], "q": 2, "done": true },
        { "n": "护照/签证(出境)", "w": [0,1,2,3], "q": 4, "done": false }
      ]
    }
  ],
  "home": {
    "collapsed": false,
    "items": [
      { "n": "关闭燃气总阀 / 灶具", "done": true },
      { "n": "锁好门窗（含阳台、卫生间）", "done": false }
    ]
  },
  "trip": { "dest": "三亚", "start": "2026-08-20", "end": "2026-08-25", "days": 6 },
  "filter": "all",
  "collapsed": {}
}
```

> 字段含义：`members` 成员表；`cats[].items[].w` 适用成员索引数组、`q` 数量、`done` 是否已装好；`home.items` 家中检查项；`trip` 行程信息。`w`/数量等可随勾选与编辑在浏览器内存中变化并自动保存。

### 输出（界面呈现）
- **进度卡片**：`已准备 35 / 92`，进度条约 38%，统计「总物品 92 / 已装好 35 / 待准备 57」。
- **分类区块**：如「💊 药品 & 健康  2/11」显示该类完成度；每项带负责人头像与 `×数量`。
- **家中检查**：`🏠 出门前 · 家中检查  9/14`，进度条显示完成比例。
- **打印视图**：隐藏所有按钮与搜索框，输出干净清单供纸质携带。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，**单文件、无框架、无外部请求**。
- 状态持久化：`localStorage`（键 `family_travel_prep_v1`），首次打开载入内置默认清单。
- 打印优化：内置 `@media print` 样式，打印时仅保留清单内容。
- 兼容：现代桌面/移动浏览器均可，移动端响应式布局。
